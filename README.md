# OpenRestore

A bedside sleep clock built from a smart bulb in a lamp you already own and a speaker you already own. Sunrise alarm, wind-down routines, sound machine. Self-hosted, LAN-only, no cloud, no subscription.

Replaces a $170 Hatch Restore plus a $60/year content subscription for about $65 in parts.

**Status:** specification. No code yet.
